# czqj

A Brave/Chrome extension that forces dark mode on websites using your own colors.

[![Download czqj](https://img.shields.io/badge/Download-czqj.zip-2ea44f?style=for-the-badge&logo=github)](https://github.com/cduqzm/czqj/releases/latest/download/czqj.zip)

## Install

1. Click **Download** above and unzip the file.
2. Open `brave://extensions` (or `chrome://extensions`) and enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped `czqj` folder.
